## 1. 产品概述

### 1.1 产品定位与核心价值

**智题 AIQuiz** 是一款面向教育机构的 **AI 智能题库系统**，覆盖"AI 出题 → 智能组卷 → 试题审核 → 在线考试"全链路。

**核心价值主张**：
- **提升出题效率**：AI 辅助生成题目，减少教师重复劳动 60%+
- **保障试卷质量**：规则引擎 + AI 双校验，难度/知识点分布可控
- **沉淀题目资产**：结构化题库管理，支持复用、查重、版本追溯
- **闭环教学流程**：从出题到考试完成数据回流，为教学分析提供基础

**产品差异化**：混合出题引擎（规则做策略师 → AI 做写手 → 模板兜底），兼顾生成质量与成本可控。

### 1.2 目标用户画像

| 角色 | 核心诉求 | 使用频率 | 关键场景 |
|---|---|---|---|
| **教师/出题员** | 快速出题、批量导入、智能组卷 | 每日 | 按知识点出题、按试卷模板组卷、Word 导出打印 |
| **教研员/审核员** | 题目质量把关、审核流转、标准统一 | 每日 | 审核 AI 生成题目、驳回修改、批量通过 |
| **系统管理员** | 用户管理、权限配置、系统监控 | 每周 | 分配角色权限、查看系统状态、配置 AI 服务商 |
| **学生（考生）** | 在线参加考试、查看成绩 | 每考试 | 限时答题、交卷后查看客观题成绩 |

### 1.3 产品边界

**当前版本（MVP）包含**：
- AI 出题（混合引擎）
- 智能组卷（参数化 + A/B 卷 + Word/PDF 导出）
- 题库管理（CRUD + 批量导入导出 + 相似度查重）
- 试题审核（审核流 + 日志 + 通知）
- 知识库（文档上传 + 知识点提取）
- 在线考试（组卷发布 + 作答 + 客观题自动判分）
- 用户权限（三角色 + 菜单权限）
- 系统设置（安全策略 + AI 服务商管理）
- 模板市场（试卷模板分享）

**当前版本不包含（明确不做）**：
- 移动端 App（仅桌面浏览器）
- 主观题 AI 自动评分（预留接口，本期不实现）
- 多租户/多机构隔离（单机构部署）
- 直播授课/视频讲解
- 第三方 LMS 集成（如 Moodle、Canvas）

### 2.2 用户故事（User Stories）

#### AI 出题

- **US-AI-01**：作为教师，我希望选择知识点后系统能自动生成题目，以便节省手动出题时间。
- **US-AI-02**：作为教师，我希望 AI 生成的题目有质量校验，以便确保入库题目格式正确、无重复。
- **US-AI-03**：作为教师，我希望出题任务可以异步执行并查看进度，以便在等待期间处理其他工作。
- **US-AI-04**：作为管理员，我希望可以配置多个 AI 服务商并灵活切换，以便在服务商故障时保障业务连续性。

#### 智能组卷

- **US-Paper-01**：作为教师，我希望设置难度分布和题型比例后系统自动组卷，以便快速生成符合要求的试卷。
- **US-Paper-02**：作为教师，我希望生成 A/B 卷以便在同一场次为不同考生提供平行试卷，防止作弊。
- **US-Paper-03**：作为教师，我希望试卷能导出为 Word 格式以便打印和组织纸质考试。
- **US-Paper-04**：作为教师，我希望在组卷前预览试卷结构和题目列表，以便确认无误后再导出。

#### 题库管理

- **US-QB-01**：作为教师，我希望批量导入 Excel 题目以便快速建设期初题库。
- **US-QB-02**：作为教师，我希望系统能检测重复题目以便避免题库冗余。
- **US-QB-03**：作为教研员，我希望查看题目修改历史以便追溯变更记录。
- **US-QB-04**：作为教师，我希望按知识点筛选题目以便查找特定章节的题目。

#### 试题审核

- **US-Audit-01**：作为审核员，我希望有统一的审核队列以便集中处理待审核题目。
- **US-Audit-02**：作为审核员，我希望批量审核功能以便快速处理大量 AI 生成的题目。
- **US-Audit-03**：作为教师，我希望审核结果能及时通知我以便了解题目是否通过。
- **US-Audit-04**：作为管理员，我希望查看审核日志以便追溯审核操作。

#### 知识库

- **US-KB-01**：作为教师，我希望上传教材文档后系统自动提取知识点以便快速构建知识体系。
- **US-KB-02**：作为教师，我希望知识点以树形结构展示以便理解层级关系。
- **US-KB-03**：作为教师，我希望将题目关联到知识点以便后续按知识点出题。

#### 在线考试

- **US-Exam-01**：作为教师，我希望创建考试并分配考生以便组织在线考试。
- **US-Exam-02**：作为学生，我希望能在线作答并自动保存答案以便完成考试。
- **US-Exam-03**：作为学生，我希望交卷后立即看到客观题成绩以便了解考试情况。
- **US-Exam-04**：作为教师，我希望查看考试统计以便分析试卷质量和学生表现。

#### 用户权限

- **US-Auth-01**：作为管理员，我希望为每个用户分配菜单权限以便控制功能访问范围。
- **US-Auth-02**：作为管理员，我希望禁用用户时立即生效以便及时回收权限。
- **US-Auth-03**：作为用户，我希望登录后只看到我有权限的功能以便减少干扰。

### 3.2 安全要求

| 维度 | 要求 | 实现方式 |
|---|---|---|
| **认证** | httpOnly + Secure + SameSite Cookie | 后端 auth.py 已实现 |
| **授权** | RBAC + 用户级菜单权限 | security.py + 前端路由守卫 |
| **密码存储** | bcrypt 哈希，成本因子 12 | passlib/bcrypt |
| **API Key 保护** | 掩码返回，加密存储 | 设置接口掩码处理 |
| **SQL 注入** | 全参数化查询 | SQLAlchemy ORM |
| **XSS 防护** | 输入过滤 + 输出转义 | DOMPurify + v-html 禁用 |
| **CSRF 防护** | SameSite Cookie + Token 双重 | SameSite=Lax |
| **限流** | 登录/AI 出题/全局三级限流 | Redis 令牌桶 |
| **审计日志** | 关键操作留痕（IP/UA/时间） | AuditLog 模型 |
| **数据备份** | 每日自动备份，保留 30 天 | backup.sh + crontab |
| **传输加密** | HTTPS（生产环境） | nginx SSL 配置 |
| **密钥管理** | 环境变量注入，不进版本库 | .env + Docker secrets |

## 5. 风险与约束

### 5.1 已知技术风险

| 风险 | 影响 | 概率 | 缓解措施 |
|---|---|---|---|
| **AI 服务商 API 变更** | 出题功能不可用 | 中 | 多服务商可切换，OpenAI 兼容协议优先 |
| **AI 生成题目质量不稳定** | 人工审核负担加重 | 高 | 规则模板兜底 + 质量校验 + 人工审核 |
| **PostgreSQL 性能瓶颈** | 大规模题库查询变慢 | 中 | 索引优化 + 查询下推 + 缓存 |
| **Redis 故障** | 限流/缓存失效 | 低 | 优雅降级（限流放行，缓存穿透到 DB） |
| **前端巨型文件维护困难** | Bug 修复/功能迭代慢 | 高 | 优先拆分，单文件 < 500 行 |
| **异步任务丢失** | 出题/组卷任务中断 | 中 | 引入持久化任务队列（ARQ/RQ） |
| **XSS/CSRF 攻击** | 用户数据泄露 | 中 | DOMPurify + SameSite Cookie + 输入过滤 |
| **密钥泄露** | AI 调用费用损失 | 低 | 密钥轮换 + 掩码返回 + 访问审计 |

### 5.2 资源约束

| 约束 | 说明 | 影响 |
|---|---|---|
| **开发人力** | 1-2 人全栈 | 迭代速度受限，需聚焦核心功能 |
| **AI 调用成本** | MiniMax API 按 token 计费 | 需控制生成数量，设置上限与告警 |
| **测试环境** | 仅有本地开发环境 | 缺少预发布环境，生产问题难提前发现 |
| **部署资源** | 单机 Docker Compose | 不支持高可用，单点故障风险 |

### 5.3 依赖约束

| 依赖 | 类型 | 说明 | 风险缓解 |
|---|---|---|---|
| **MiniMax API** | 外部服务 | AI 出题核心依赖 | 多服务商可切换（OpenAI/DeepSeek 等） |
| **PostgreSQL 15** | 基础设施 | 主数据库 | 定期备份，可迁移至云托管数据库 |
| **Redis 7** | 基础设施 | 缓存/限流 | 故障可降级，非核心路径 |
| **Docker** | 部署工具 | 容器化部署 | 可迁移至 K8s 或云容器服务 |
| **Vue 3 / Element Plus** | 前端框架 | UI 组件库 | 国内主流方案，社区活跃 |
| **FastAPI** | 后端框架 | API 服务 | Python 生态，异步支持好 |

### 5.4 技术债务清单

| 债务 | 位置 | 影响 | 偿还优先级 |
|---|---|---|---|
| **版本控制失效** | 全仓 | 任何事故 = 项目归零 | 🔴 立即 |
| **密钥未轮换** | backend/.env, deploy/.env | 泄露 Key 仍在使用 | 🔴 立即 |
| **前端认证半途而废** | api/index.js, stores/auth.js | XSS 可窃取 token | 🔴 立即 |

| **裸线程任务队列** | tasks.py | 重启丢任务 | 🟠 高 |
| **测试覆盖率低** | tests/ | 回归风险高 | 🟠 高 |
| **CI 未生效** | .github/workflows/ci.yml | 代码质量无门禁 | 🟠 高 |

| **权限表不一致** | 前后端各维护一份 | 权限漏洞 | 🟡 中 |
